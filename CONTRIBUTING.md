# Contributing

1. Open an issue describing the problem, expected behavior, and responsible-use impact.
2. Create a focused branch and keep secrets, real personal data, and restricted platform datasets out of commits.
3. Add or update tests for behavior changes.
4. Run the web build and tests before submitting a pull request.
5. Explain scoring, data provenance, assumptions, uncertainty, and limitations for analytical changes.

Contributions must not add scraping, demographic inference, unsupported fraud claims, hidden ranking factors, or guaranteed financial claims.
