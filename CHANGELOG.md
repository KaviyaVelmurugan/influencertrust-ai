# Changelog

## [1.0.0] - 2026-08-21

### Added

- Explainable creator ranking and authenticity-risk screening
- Campaign caption-compliance audit and creator briefs
- ROI and ROAS sensitivity scenarios
- Browser-local CSV analysis and report import
- Live YouTube Data API v3 connector
- Objective-aware multi-channel comparison shortlist
- Private saved projects with Sign in with ChatGPT
- CSV export, print-to-PDF reporting, and PWA installation
- Accessibility, timeout, error-handling, and security hardening

### Responsible-use boundaries

- Scores remain decision support rather than proof of fraud.
- ROI outputs remain scenarios rather than guaranteed forecasts.
- Public YouTube observations do not infer private demographics or conversions.
